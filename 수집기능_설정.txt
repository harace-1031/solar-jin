검색 지번 수집 및 엑셀 다운로드
1. 이 폴더 안의 파일과 dist 폴더를 기존 GitHub 저장소 루트에 덮어 올리고 Commit changes를 누릅니다.
2. Render Environment: SUPABASE_URL, SUPABASE_SECRET_KEY, ADMIN_PASSWORD를 설정합니다. 비밀키는 GitHub에 올리지 않습니다.
3. Supabase SQL Editor에서 함께 제공된 검색기록표_생성.sql을 실행하세요. 기존 searched_parcels 표와 별도로 중복 조회용 표를 만듭니다. 공개 접근 정책은 만들지 않습니다.
4. 배포 후 사이트에서 필지 하나를 조회합니다.
5. https://solar.jinenergy.co.kr/admin 에서 ADMIN_PASSWORD를 입력하고 엑셀 다운로드를 누릅니다.
   기본 주소 https://solar-jin.onrender.com/admin 도 가능합니다.
6. 내려받은 xlsx에서 방금 조회한 지번이 있으면 연결까지 정상입니다. 오류가 나면 설정을 확인합니다.

저장 범위: 토지 조회가 완료된 공식 지번과 검색일시를 조회할 때마다 저장합니다. 같은 지번의 두 번째·세 번째 조회도 각각 별도 행입니다. 실패한 검색어, 검색 후보 목록, 설치 전 과거 조회는 저장하지 않습니다.
검색일시는 저장소에 기록된 시각이며 엑셀에서는 한국시간으로 표시합니다. 이름과 IP는 이 수집 표에 저장하지 않습니다. 호스팅업체 자체 운영 로그와는 별개입니다.
저장소 오류가 나도 토지 조회는 계속되며 조회 상태에 저장 실패가 표시됩니다.
다운로드에는 비밀번호가 필요하며 목록을 공개하지 않습니다. 빈 표는 제목만 있는 엑셀로 내려받아집니다.
무료 저장소의 중지·용량 제한이나 외부 연결 장애 시 수집이 중단될 수 있으므로 주기적으로 다운로드해 보관하세요.
