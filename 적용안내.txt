위성사진 포함 CAD 다운로드 업데이트

압축 안의 app.py, server.py, cad_export.py, requirements.txt, gunicorn.conf.py와 dist 폴더를 기존 GitHub 저장소에 덮어 올리고 Commit changes를 누르세요.
requirements.txt가 반드시 함께 올라가야 새 기능이 설치됩니다. Render의 Build Command는 pip install -r requirements.txt입니다.
배포가 Live가 되면 Ctrl+F5로 새로고침하고 필지를 조회하세요.
배치도 아래 위성사진 포함 CAD 다운로드 (ZIP) 버튼을 누르면 도면과 위성사진을 내려받습니다.

다운로드 ZIP은 모두 압축을 푸세요. layout.dxf와 satellite.jpg를 같은 폴더에 두고 도면을 엽니다.
사진은 DXF 외부 참조입니다. 사진 파일을 따로 옮기거나 이름을 바꾸면 연결이 끊어집니다.
사진이 안 보이면 AutoCAD XREF에서 satellite.jpg 경로를 같은 폴더의 파일로 다시 지정하세요.
SATELLITE 레이어를 끄면 사진만 숨길 수 있습니다. 부지 경계와 모듈은 각각 편집 가능합니다.
PRINT_1_1000 배치, 모듈 규격·각도·단수·이격거리와 설계용량 상한은 유지합니다.
사진은 현재 서비스와 같은 Esri 영상이며, EPSG:5179로 좌표 변환하여 도면과 정렬합니다.
원본 지적 경계·위성영상의 위치 오차는 남습니다. 정밀측량 도면이 아닙니다.
네이버·카카오 지도는 사용하지 않습니다. 도형만 DXF 다운로드도 기존처럼 사용할 수 있습니다.
서버 재시작으로 배치 정보가 만료됐다는 안내가 나오면 배치도에서 다시 그리기를 누르세요.
